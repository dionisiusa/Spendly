# 💰 Spendly

Aplikasi manajemen keuangan pribadi untuk membantu mencatat, memantau, dan menganalisis pengeluaran serta hutang secara sederhana.

## ✨ Fitur

### 📊 Dashboard
- Ringkasan total pengeluaran
- Pengeluaran bulan berjalan
- Ringkasan hutang
- Transaksi terbaru

### 💸 Pengeluaran
- Tambah transaksi pengeluaran
- Edit transaksi
- Kategori pengeluaran
- Pemilihan dompet
- Tanggal transaksi
- Catatan transaksi

### 💳 Hutang
- Tambah hutang
- Edit hutang
- Deskripsi hutang
- Nominal hutang
- Tanggal jatuh tempo
- Status hutang: Aktif / Lunas
- Hapus hutang

### 📈 Analytics
- Total pengeluaran
- Cash flow bulanan
- Pengeluaran berdasarkan kategori
- Persentase pengeluaran
- Insight pengeluaran

### 🎨 UI
- Responsive design
- Dark mode
- Tailwind CSS
- Layout menggunakan AppShell
- Komponen berbasis React
- Tampilan sederhana dan mobile-friendly

### 🗄️ Supabase
- Authentication
- Login dan Register
- Database PostgreSQL
- Penyimpanan transaksi
- Penyimpanan hutang
- Penyimpanan kategori
- Penyimpanan dompet
- Row Level Security (RLS)
- Data pengguna terisolasi berdasarkan `user_id`

## 🛠️ Teknologi

- Next.js
- React
- JavaScript
- Tailwind CSS
- Supabase
- PostgreSQL
- Vercel
